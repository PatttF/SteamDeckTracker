# SDTracker
Steam Deck focused tracker based on Little Piggy Tracker, I want to take the workflow of the classic handheld tracker and expand it to use all of the power of modern computing. There will be a lot added/changed from the base LGPT code so while the basic usage will be the same this will be so much more.  Now with 16 tracks instead of 8, MUCH improved sample format support thanks to ffmpeg integration, a mixer page, LV2 plugin support, and much more to come. All external files moved to SDTracker in users Documents folder. This is all generated on first launch, samples just need added to the samplelib folder. The default samples  as well as my Mutated Instruments LV2 plugin can be installed via the projects page. 


In steam search for SDTracker control layout in community to correctly map your controls.


Instruments 90 - 9F are dedicated for LV2 plugins.
